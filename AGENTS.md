# Project Instructions

## Commands

- `uv sync` — install dependencies.
- `uv run pytest` — run the whole test suite.
- `uv run pytest tests/test_home.py` — run one test file.

These commands apply once the project setup task has established the Python project and tests.

## Rules

- Dependencies belong in `pyproject.toml`. Ask before adding a dependency.
- Tasks are GitHub issues; work on one issue at a time.
- Read the acceptance criteria before starting and before closing an issue.
- Commit regularly.

## Documents

- `_docs/plan.md` — project scope and agreed product decisions.
- `_docs/process.md` — how work is organized.
- `_docs/tasks.md` — local backlog reference with links to GitHub issues.
