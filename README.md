# PEX — Personal Expense Analyzer

A planned personal expense tracking website for phone and computer, using Django, PostgreSQL, HTMX, and Chart.js.

The first version includes one private account with persistent login, manual KZT expense entry, customizable categories, current-month summaries, 12-month trends, automatic recurring payments, 30-day Trash, and complete-history CSV export. Hosting will use an owned server selected later; date rules use Asia/Qyzylorda.
